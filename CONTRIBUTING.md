# Contributing

Thanks for helping improve Legacy Clicker.

## Before opening an issue

- Check existing issues and pull requests first.
- Use a clear title and describe the exact problem.
- Include your Windows version and Legacy Clicker version.
- Add reproduction steps for bugs.
- Never include passwords, tokens, or private information.

## Pull requests

1. Create a focused branch from `main`.
2. Keep each pull request limited to one change.
3. Use a clear commit message.
4. Update documentation when behavior changes.
5. Confirm that documentation links and formatting are valid.

## Commit messages

Use short, specific messages such as:

- `fix: prevent duplicate click loop`
- `docs: clarify antivirus warning`
- `ci: validate release files`

## Scope

The public repository currently distributes release builds and project documentation. Do not claim unverified features or upload unofficial executables.
